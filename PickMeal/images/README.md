# 메뉴 사진 넣는 곳

이 폴더(`images`) 안에 아래 **파일명 그대로** 저장하면 카드에 자동으로 뜹니다.
파일이 없는 메뉴는 지금처럼 이모지가 그대로 나옵니다. 한 장씩 채워도 됩니다.

## 저장 규칙

- 파일명은 아래 표의 이름 **그대로** (`menu01.jpg` 처럼). 슬래시(/)는 넣지 마세요
- `.jpg` 권장. `.png` 로 저장해도 자동으로 찾습니다
- 카드 비율이 **가로:세로 = 1.25 : 1** 이라 가로가 조금 긴 사진이 잘 맞습니다
- 600x480 정도면 충분합니다. 큰 원본은 줄여서 넣어주세요
- 전부 안 채워도 됩니다. 넣은 것만 사진으로 바뀝니다
