파일이 없는 메뉴는 지금처럼 이모지가 그대로 나옵니다. 하나씩 채워도 됩니다.

- 파일명은 **숫자만** (한글 파일명은 Mac/Windows 간 인코딩 문제가 납니다)
- `.jpg` 권장. `.png` 도 자동으로 찾습니다
- 카드 비율이 가로:세로 = 1.25:1 이라 **가로가 조금 긴 사진**이 잘 맞습니다
- 600x480 정도면 충분합니다. 너무 큰 원본은 줄여서 넣어주세요
